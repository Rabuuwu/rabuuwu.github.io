Problem and scope

The application handles customer requests and connects them with the existing CRM. I built a mobile client and its backend instead of treating the app as an isolated interface. The work is part of the company environment.

What I built myself

I independently designed and implemented the UI, database and security controls. I built the React Native / TypeScript / Expo application, its Express backend and the integration of customer requests with the CRM.

What the application does

  • A mobile interface for the customer-request workflow.
  • A backend connecting requests with the CRM.
  • A database and security controls designed for the application.

Client, backend and CRM

React Native and Expo provide the mobile client; TypeScript is used in the app and Express provides the backend. The backend integrates the request flow with the CRM.

This project is separate from D&D Companion: that personal application uses Vite and Capacitor, not this React Native stack.

Verification

I tested the application after implementing its interface, data and integration. I present it as a test version, not as a completed public customer rollout.

Current status

The current published description is a test version. The commercial case study contains no company code, internal addresses or screenshots with customer information.
