Problem i zakres

Aplikacja obsługuje zgłoszenia klientów i łączy je z istniejącym CRM. Zbudowałem klienta mobilnego wraz z backendem, zamiast traktować aplikację jako odizolowany interfejs. Projekt jest częścią środowiska firmy.

Co zbudowałem samodzielnie

Samodzielnie zaprojektowałem i zaimplementowałem UI, bazę danych i zabezpieczenia. Zbudowałem aplikację React Native / TypeScript / Expo, backend Express oraz integrację zgłoszeń klientów z CRM.

Co robi aplikacja

  • Mobilny interfejs procesu zgłoszeń klientów.
  • Backend łączący zgłoszenia z CRM.
  • Baza danych i zabezpieczenia zaprojektowane dla aplikacji.

Klient, backend i CRM

React Native i Expo tworzą klienta mobilnego, TypeScript jest wykorzystywany w aplikacji, a Express obsługuje backend. Backend integruje przepływ zgłoszeń z CRM.

To osobny projekt od D&D Companion: moja aplikacja RPG korzysta z Vite i Capacitor, a nie z tego stosu React Native.

Weryfikacja

Przetestowałem aplikację po zaimplementowaniu interfejsu, danych i integracji. Pokazuję ją jako wersję testową, nie zakończone publiczne wdrożenie dla klientów.

Aktualny status

Aktualny opis dotyczy wersji testowej. Case study komercyjne nie zawiera kodu firmy, wewnętrznych adresów ani zrzutów z informacjami klientów.
